# 音を分ける（音源分離・Demucs・tools/separate.py）環境の部品。本体とは別の .venv-sep に入れる（PyTorch が数 GB あるため）。

# PyTorch の CUDA 版（NVIDIA の GPU で動かす）は PyPI に無いので、先に PyTorch の置き場（index-url）から入れ、残りを PyPI から入れる:
#
#   py -3.14 -m venv .venv-sep
#   .venv-sep\Scripts\python.exe -m pip install torch==2.11.0+cu128 torchaudio==2.11.0+cu128 --index-url https://download.pytorch.org/whl/cu128
#   .venv-sep\Scripts\python.exe -m pip install -r requirements-sep.txt
#
#   （1回で入れるなら: pip install -r requirements-sep.txt --extra-index-url https://download.pytorch.org/whl/cu128 。
#     PyTorch の置き場にも numpy 等の写しがあるので、上の2段に分ける方が PyPI の物だけを確実に使える）
#   NVIDIA の GPU が無い PC は CPU 版: 上の cu128 を cpu に、版の +cu128 を +cpu に読み替える（遅いが動く）。
