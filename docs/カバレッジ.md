# テストのカバレッジの記録

テスト（pytest）でどのコードを通ったかの記録。測り方は `.coveragerc` の頭と CLAUDE.md の「テスト・実行」。
新しく測った時は、下に節を足す（前の記録は消さない＝比べられるように）。

## 2026-11-10（v0.2.0・コミット fcb3764＝コードは e2523f5 と同じ）

流れの計算をまるごと Numba にした直後。テストは 674 件が全部通った（曲の解析の答え合わせは控えに頼らず計算した＝`AUTOMAP_FULL_ANALYSIS=1`）。

- 測り方: `AUTOMAP_FULL_ANALYSIS=1 COVERAGE_FILE=<控えの場所>/.coverage .venv/Scripts/python.exe -m pytest --cov --cov-report=html:<出す場所>`
  （36 秒）。並べた働き手の分も、テストが起こす子のプロセス（作り直しの compose など）の分も入る。
- **流れの計算（`automap/flow_nb.py`）は別に測った**: Numba でコンパイルした関数は coverage が追えず、ふつうに測ると 228 / 987（23.1%） と出る。
  `NUMBA_DISABLE_JIT=1` で tests/test_flow_nb.py・test_flow_same.py だけを流して測った（1 分 40 秒・20 件が通った＝コンパイルしない時も
  同じ答え）。下の表の flow_nb.py の行と合計はその値で置き換えた。置き換える前の全体は 15,037 / 20,571（73.1%）。
- 数えたのは行（分かれ道ごとの数え方はしていない）。
