# リリースノート

## v1.0.0（最初の公開版）

Auto Note Plotter（ANP）は、Beat Saber の譜面を自動で作る Windows のアプリです。曲を取り込むと最初の譜面ができ、区間ごとに方針（**意思入れ**）を
足して何度でも作り直せます。できた譜面は Beat Saber にそのまま書き出せるほか、NLM（[Non-Linear Mapper Oz-Co2 版](https://github.com/Oz-Co-two/nlm-oz-co2)）の
プロジェクトファイル（.nlmf）なので、NLM で開いて手直しやライティングもできます。

**ノーツを置くのに AI（学習済みのモデル）は使いません。** どこに打つか・どちらの手でどの向きに切るかは、BeatLeader のランク譜面から集めた
「型」（人の譜面によく出る数回の振りのまとまり）と、決まりと計算で決めます。学習済みのモデルを使うのは、曲を 4 つの音に分ける部品（Demucs）と、
★を見積もる部品（nlm-rating）だけです。

使い方は [チュートリアル](tutorial.md) を見てください。

### できること

**曲を取り込む**
- 音源（flac・wav・mp3・ogg・m4a・aac・opus・aiff・wma）を選ぶと、歌・ドラム・ベース・その他の 4 つの音に分け、テンポ・無音追加・曲の構成を
  調べて（NLM と同じ解析）、最初の譜面まで作ります。
- 取り込みの途中で、型のライブラリ（下）の基本設定を決められます。

**自動で作る譜面**
- 歌・ドラムの打点と、曲の盛り上がり・くり返し・音の途切れに合わせて打ちます。
- 同じ音楽の区間は同じリズムと振りをくり返し（2 回目のサビは左右反転など）、短いフレーズは右 → 左と反転して続けます。
- 左右の受け渡し・短い往復・1 回だけの珍しい型を使った「決め」も入ります。
- 歌の立ち上がりが拍からばらつく所では、迷った歌の打点をキック・スネアの鳴る拍へ寄せます。

**意思入れ（区間ごとの指示）**
- タイムラインで区間を選び、元にする音（歌・ドラム・ベース・その他の楽器）・量・スネアやキックに打つ・空きを埋める・歌を拍に寄せる・休み・
  両手・振りの速さ・動きの大きさ・横の広がり・腕の高さ・斜め・向きの変わり方・型の変わり方・大技・型の幅・★の帯・決め、を付けられます。
- 「同じ振り」で、離れた区間に同じ振りや、ノーツを足したアレンジをくり返せます。
- 量のラインで、曲全体のノーツの量を場所ごとに増減できます。

**作り直し・見比べ**
- 作り直しは「変えた所だけ」（前の譜面に寄せる）か「全部」。選んだ区間だけの作り直しもできます。
- 作り直すたびに履歴が残り、前の版に戻せます。区間ごとに「別の案」を作って見比べ、選べます。
- NLM の 3D の表示で譜面を見ながら、曲と分けた 4 つの音を聞けます。区間ごとに人の譜面との近さや崩れを点検できます。

**型のライブラリ**
- 曲ごとに、型の元にするランク譜面をアップロード年（年ごとに選べる・自動もある）・★の帯・型の頻度・置き方の難しさで絞れます。

**難易度を作り分ける（展開）**
- 基準の難易度から、上下の難易度をまとめて作ります（下は間引き、上は足す）。同じ音楽の区間のくり返しは、ほかの難易度でもそろえます。
- 難易度ごとに★を見積もり、NJS と見え始める距離（JD）を★・BPM・難易度から決めます。3D で決めた NJS を基準に使うこともできます。

**Beat Saber に書き出す**
- 曲の情報・カバー画像・書き出す難易度を決めて、Beat Saber の譜面フォルダへ直接書き出します。アプリ用のプレイリストにも足します。
- 音の小さい曲の音量を、カスタム曲によくある大きさまで自動で上げることもできます（選べます）。

**遊んだリプレイを見る**
- BeatLeader の Mod が記録したリプレイを、BeatLeader のリプレイアプリ（アプリに同梱）で開きます。
- アプリの左下の欄で譜面とリプレイの再生位置をそろえて見られるので、無理のあるプレイや崩れた所を見ながら指示を付けられます。
- リプレイの一覧は「この曲」と「全部の履歴」。★・ミス・バッド・途中でやめたプレイの印が出ます。

**NLM との行き来**
- NLM で手直ししたクリップは、アプリで作り直しても残ります。触っていないが残したい所は、クリップの名前に「固定」を付けます。

**アプリの更新**
- 起動した時に新しい版を確かめ、「更新」の窓からダウンロードして入れ替えます（失敗したら前の版に戻ります）。

### 動かすのに要る物

- Windows（64 ビット）。Windows 11 で確かめています。
- 音を分ける部品: 初めて起動した時に、アプリの中からダウンロードしてインストールします（GPU 版＝NVIDIA のグラフィックボードがある時
  約 3.1GB／CPU 版 約 0.5GB）。インストールした後は、インターネットにつながっていなくても動きます。
- 作業フォルダ: 1 曲につき約 100MB。
- NLM（任意）: 手直し・ライティングに使います。無くてもアプリは動きます。
- BeatLeader の Mod（任意）: 遊んだリプレイを見る時に使います。

### 知っておいてほしいこと

- テンポが途中で変わる曲は、まだ扱えません。
- アプリに署名が無いため、初めて起動した時に「Windows によって PC が保護されました」と出ることがあります（「詳細情報」→「実行」）。
- ★は BeatLeader の計算（PPv4.1）を手元で近似した値です。本家の★とは数 % ずれることがあります。
- リプレイの見え始める距離（JD）は、遊んだ時の設定のままです（アプリの譜面の JD とは別）。
